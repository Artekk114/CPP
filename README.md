# CrossApp
Наскрізний проєкт з крос-платформного програмування.

Предметна область: Замовлення. Сутності: Customer (клієнт), Product (товар), Order (замовлення), OrderLine (рядок замовлення).
Призначення: оформлення замовлень і підрахунок сум.

## Імпорт даних (Лабораторна 3)

Програма підтримує автоматичне завантаження даних із файлів `.csv` та `.json`. 
Якщо аргументи командного рядка не передані, за замовчуванням завантажується `data/sample.csv`.

*Приклад CSV:*
```csv
type;id;name;price;note
P;P-001;Ноутбук;25000.50;Акція
W;W-001;Головний склад
P;P-002;Мишка;800;
* Товари (`P`): `P;ID;Назва;Ціна;[Примітка]` *(Примітка — необов'язкове поле)*
* Склади (`W`): `W;ID;Назва`
